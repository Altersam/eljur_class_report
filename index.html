GradeReport

Генератор отчётов успеваемости из PDF-журналов электронного дневника

⬇ Скачать GradeReport.exe 📊 Демо дашборда GitHub

Что это?

GradeReport — бесплатная утилита для автоматического создания отчётов из PDF-журналов электронного дневника. Программа извлекает данные об учениках, предметах, оценках и учителях, а затем генерирует:

  • Excel (.xlsx) — сводная таблица средних баллов и детальный лист с оценками и пропусками (НКИ)
  • JSON (.json) — структурированные данные для дальнейшей обработки
  • HTML (.html) — интерактивный дашборд с графиками, полностью автономный

Как использовать

1
Скачайте GradeReport.exe
2
Запустите и перетащите PDF-журнал в окно
3
Выберите папку и форматы отчётов
4
Нажмите «Сгенерировать»

Требования

Windows 10/11 — других зависимостей нет. Программа полностью автономна (~66 MB).

Для разработчиков (Python)

pip install pymupdf openpyxl PyQt5
python gui.py

Сборка из исходников

git clone https://github.com/Altersam/eljur_class_report.git
cd eljur_class_report
pip install pymupdf openpyxl PyQt5 pyinstaller
pyinstaller --clean --onefile --windowed --name GradeReport --add-data "dashboard.html;." gui.py

Результат: dist/GradeReport.exe

Формат PDF

Программа ожидает стандартный формат журнала электронного дневника:

  • Страницы с оценками: содержат «Наименование предмета», список учеников и оценки по датам
  • Страницы учителей: содержат «Фамилия, имя, отчество учителя» и пройденный материал
