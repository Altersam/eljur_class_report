# GradeReport — Генератор отчётов из PDF-журнала

Автоматическая генерация отчётов успеваемости из PDF-журналов электронного дневника.

## Возможности

- **Парсинг PDF** — извлечение данных об учениках, предметах, оценках, датах и учителях по координатам
- **Excel (.xlsx)** — два листа: «Сводка» (таблица средних баллов) и «Детально» (оценки и НКИ по каждому ученику)
- **JSON (.json)** — структурированные данные с персональными списками предметов для каждого ученика
- **HTML (.html)** — интерактивный дашборд с графиками, полностью автономный (Chart.js через CDN)

## Требования

- Python 3.10+
- `pymupdf` — для парсинга PDF
- `openpyxl` — для генерации Excel
- `PyQt5` — для GUI (опционально)

## Установка

```bash
pip install pymupdf openpyxl PyQt5
```

## Использование

### Через GUI

```bash
python gui.py
```

Или запустите `GradeReport.exe` — перетащите PDF в окно, выберите папку и форматы, нажмите «Сгенерировать».

### Через командную строку

```bash
python report.py журнал.pdf
```

Файлы отчётов будут сохранены рядом с исходным PDF.

## Структура проекта

| Файл | Описание |

## Как работает парсинг

Извлечение оценок основано на **координатном подходе** (PyMuPDF `get_text("dict")`):

1. На каждой странице определяются колонки дат по X-координатам заголовков
2. Месяцы определяются по заголовкам (`Январь`, `Февраль` и т.д.) и границам `ПР`/`КР`/`СР`
3. Оценки каждого ученика сопоставляются с колонками дат по близости X-координат
4. Пропуски (`Н`) и оценки (2–5) извлекаются корректно, без ложных срабатываний

## Сборка exe

```bash
pyinstaller --clean GradeReport.spec
```

Результат: `dist/GradeReport.exe` — один файл, работает без Python.

## Формат PDF

Ожидается стандартный формат журнала электронного дневника:
- Страницы с оценками: содержат «Наименование предмета», список учеников и оценки по датам
- Страницы учителей: содержат «Фамилия, имя, отчество учителя» и пройденный материал
